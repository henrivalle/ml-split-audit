# Contributing · Como contribuir

Run the README example and choose a [beginner task](https://github.com/henrivalle/ml-split-audit/contribute). For a bug report, include the command, the expected result, and a minimal synthetic input. English and Portuguese contributions are welcome.

Execute o exemplo do README e escolha uma [tarefa inicial](https://github.com/henrivalle/ml-split-audit/contribute). Para relatar um erro, forneça o comando, o resultado esperado e uma entrada sintética mínima. Contribuições em português e inglês são bem-vindas.

```sh
python -m pip install .
python -m unittest discover -s tests -v
```
